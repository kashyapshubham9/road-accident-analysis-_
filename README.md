# Road Traffic \& Accident Data Analysis

## Objective

Analyze road traffic and accident data to identify accident trends, high-risk locations, vehicle patterns and severity distribution.

## Tools

* Microsoft Excel
* SQL
* Power BI
* Basic statistical analysis

## Dataset

10,000 traffic/accident observations covering 2025.

## Workflow

1. Cleaned and standardized raw data.
2. Performed exploratory analysis in Excel.
3. Used SQL for filtering, aggregation and trend analysis.
4. Designed an interactive Power BI dashboard.
5. Created a location risk score using accident frequency, severity and traffic exposure.

## Key outputs

* Monthly accident trend
* Top accident-prone locations
* Vehicle-wise accident distribution
* Severity analysis
* Weather and time-period analysis
* Traffic volume vs accident relationship
* Location risk classification
